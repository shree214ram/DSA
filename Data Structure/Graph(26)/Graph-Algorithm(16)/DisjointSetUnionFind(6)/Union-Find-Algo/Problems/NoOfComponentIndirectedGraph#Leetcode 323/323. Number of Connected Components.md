323. Number of Connected Components in an Undirected GraphProblem StatementYou have a graph of n nodes labeled from 0 to n - 1. You are given an integer n and an array edges where edges[i] = [a_i, b_i] indicates that there is an undirected edge between node a_i and node b_i in the graph.Return the total number of connected components in the graph.

ExamplesExample 1Input: n = 5, edges = [[0,1],[1,2],[3,4]]
Output: 2
Visual:
Component 1: 0 - 1 - 2
Component 2: 3 - 4

Example 2Input: n = 5, edges = [[0,1],[1,2],[2,3],[3,4]]
Output: 1
Visual:Component 1: 0 - 1 - 2 - 3 - 4Constraints$1 \le n \le 2000$$0 \le \text{edges.length} \le 5000$$\text{edges}[i].\text{length} == 2$$0 \le a_i, b_i < n$$a_i \neq b_i$There are no repeated edges (no duplicate edges in edges).

Useful Hints to Keep in MindPattern Options: You can solve this using either:Disjoint Set Union (DSU / Union-Find): Start with n components and decrement the count each time a successful union merges two distinct sets.DFS / BFS Traversal: Build an adjacency list, maintain a visited array, and count how many times you start a new search pass over an unvisited node.
