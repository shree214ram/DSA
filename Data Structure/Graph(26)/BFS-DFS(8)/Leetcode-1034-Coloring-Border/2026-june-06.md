```javascript
var colorBorder = function(grid, row, col, color) { 
    const m = grid.length;
    const n = grid[0].length;
    
    // Create a deep copy of the original grid to return the final modified version
    const finalGrid = grid.map(r => [...r]);
    // Create a 2D array to track visited coordinates
    const visited = Array.from({ length: m }, () => Array(n).fill(false));
    
    // Step 1: Capture the original starting component color
    const originalColor = grid[row][col];
    
    const dfs = (r, c) => {
        // Step 2: Handle boundary limits and color mismatch
        if (r < 0 || r >= m || c < 0 || c >= n || grid[r][c] !== originalColor) {
            return false; // Not a valid internal part of the matching component
        }
        
        if (visited[r][c]) {
            return true; // Already processed part of the component
        }
        
        // CRITICAL FIX: Mark visited immediately BEFORE moving to neighbors
        visited[r][c] = true;
        
        // Step 3: Explore all 4 directions recursively
        const left  = dfs(r, c - 1);
        const right = dfs(r, c + 1);
        const up    = dfs(r - 1, c);
        const down  = dfs(r + 1, c);
        
        // Step 4: If it touches a boundary OR any neighbor isn't part of the component, it's a border!
        if (!(left && right && up && down)) {
            finalGrid[r][c] = color;
        }
        
        return true;
    };
    
    dfs(row, col);
    return finalGrid;
};

```

In Depth-First Search, the program does not check all four directions at the exact same time; instead, it dives **all the way to the end** of the very first direction before even looking at the second direction.

Here is how the execution line-by-line forces this deep travel:

```text
1. You are at (0,0).
2. It hits the line: `const left = dfs(0, -1);` -> This immediately returns false (out of bounds).
3. It moves to the next line: `const right = dfs(0, 1);` -> This pauses (0,0) completely!
   
   [The Jump] 
   Control jumps entirely inside (0,1). (0,0) is sitting on the call stack waiting.
   
   4. Inside (0,1), it starts its own lines from the top:
      - `dfs(0, 0)` (left) -> returns true (already visited).
      - `dfs(0, 2)` (right) -> returns false (out of bounds).
      - `dfs(-1, 1)` (up) -> returns false (out of bounds).
      - `dfs(1, 1)` (down) -> grid value is 2, returns false.
   5. (0,1) finishes completely, updates its border, and returns control back to (0,0).

6. Now (0,0) resumes right where it left off, moving to its next line: `const up = dfs(-1, 0);`

```

### Visual Call Stack Timeline

```text
Time 1: [dfs(0,0)] ───────────► Pauses at "right" branch to explore deeper.
Time 2:   └───► [dfs(0,1)] ───► Executes all 4 of its directions completely and finishes.
Time 3: [dfs(0,0)] ───────────► Resumes and moves down to its next line: "up" branch.
Time 4:   └───► [dfs(1,0)] ───► Executes all 4 of its directions completely and finishes.

```

That is why it is called **Depth**-First: the recursive function calls itself on a neighbor, crashing deep into that neighbor's branch before the current cell can finish evaluating its remaining directions.
