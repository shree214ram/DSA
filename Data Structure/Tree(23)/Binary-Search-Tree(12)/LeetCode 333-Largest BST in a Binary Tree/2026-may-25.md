**Problem Statement:**
Given the root of a binary tree, find the largest subtree, where "largest" means the subtree with the maximum number of nodes, and that subtree must be a Binary Search Tree (BST).

*Note: A subtree of a binary tree is any node of the tree along with all of its descendants.*

---

#### 📊 Examples

**Example 1:**

```text
      10
     /  \
    5    15
   / \     \
  1   8     7

Output: 3
Explanation: The largest BST subtree here is highlighted below:
    5
   / \
  1   8
The subtree rooted at node 5 has 3 nodes (1, 5, 8) and satisfies all BST properties. 
The entire tree is not a valid BST because the value 7 in the right subtree is smaller than 10.

```

**Example 2:**

```text

   / \

 /     \

Input: root = [3, 2, 4, 1, null, null, 5]

Explanation: The entire tree is a valid Binary Search Tree. Therefore, the largest BST subtree is the tree itself, which contains 5 nodes.

```
