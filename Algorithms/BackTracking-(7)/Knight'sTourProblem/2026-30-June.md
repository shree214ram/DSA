### 🚨 Why standard Backtracking hits a wall here (The Interviewer's Secret)

If you run a naive backtracking search on an $8 \times 8$ board, it will hit **Time Limit Exceeded (TLE)** instantly. The time complexity is $O(8^{N^2})$, which is an astronomical number of paths to explore.

To make it pass, top-tier engineers use **Warnsdorff's Rule**: a simple heuristic (rule of thumb) where you always move to the neighbor that has the **fewest onward moves**. This slashes execution time from millions of years to a few milliseconds.

---

### 🏆 The Production-Ready Solution

Here is how you cleanly structure the code, fix the 8-directional offsets, and capture the win state:

```javascript
var solveKnightsTour = function (n) {
    // 1. Initialize the board with -1
    const grid = Array.from({ length: n }, () => Array(n).fill(-1));
    
    // 2. Define the exact 8 'L' shape movements
    const dRow = [2, 1, -1, -2, -2, -1, 1, 2];
    const dCol = [1, 2, 2, 1, -1, -2, -2, -1];
    
    // Helper to count valid onward moves (Warnsdorff's Rule)
    const getMoveCount = (r, c) => {
        let count = 0;
        for (let i = 0; i < 8; i++) {
            const nr = r + dRow[i];
            const nc = c + dCol[i];
            if (nr >= 0 && nr < n && nc >= 0 && nc < n && grid[nr][nc] === -1) {
                count++;
            }
        }
        return count;
    };

    let solved = false;

    const rec = (r, c, moveIndex) => {
        // Base Case: If we've filled all N * N cells, we are done!
        if (moveIndex === n * n) {
            solved = true;
            return;
        }

        // Gather all valid next jumps with their prospective onward move counts
        const candidates = [];
        for (let i = 0; i < 8; i++) {
            const nr = r + dRow[i];
            const nc = c + dCol[i];
            
            if (nr >= 0 && nr < n && nc >= 0 && nc < n && grid[nr][nc] === -1) {
                candidates.push({ nr, nc, onwardMoves: getMoveCount(nr, nc) });
            }
        }

        // Warnsdorff's Rule: Sort candidates to prioritize the tightest corners first
        candidates.sort((a, b) => a.onwardMoves - b.onwardMoves);

        // Backtracking loop
        for (const { nr, nc } of candidates) {
            grid[nr][nc] = moveIndex; // Choose
            
            rec(nr, nc, moveIndex + 1); // Explore
            
            if (solved) return; // If a child found the perfect tour, stop backtracking!
            
            grid[nr][nc] = -1; // Unchoose
        }
    };

    // Start tour at 0,0 marking it as move 0
    grid[0][0] = 0;
    rec(0, 0, 1);

    return solved ? grid : [];
};

```
