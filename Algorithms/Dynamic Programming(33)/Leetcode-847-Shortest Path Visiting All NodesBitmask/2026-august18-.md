The key difference is that **MST (Kruskal/Prim's)** selects a subset of edges to build a static spanning tree where you never re-visit nodes or travel back-and-forth along paths, whereas **LeetCode 847** requires finding a single continuous walk through time where you are allowed to revisit nodes and edges multiple times to touch all vertices—making it a Traveling Salesperson / BFS State-Space Problem rather than a Spanning Tree problem.

Regarding your bitmask and BFS setup, you have the core idea right, but there are a few syntax and state-tracking adjustments needed:

* **Target Bitmask:** `(1 << n) - 1` (not `(n << 1) - 1`).
* **Multi-Source Initialization:** You must push **all** starting nodes `0` through `n-1` into the queue initially at `dist = 0` with their starting mask `(1 << i)`, since the path can begin anywhere.
* **Visited State:** Tracking visited nodes requires `visited[node][mask]` (size `n x (1 << n)`), because reaching the same node with a new set of visited nodes is a completely different valid state.
* **Neighbor Mask:** The new mask when moving to neighbor `x` is `mask | (1 << x)` (bitwise OR to turn on the bit).

```javascript
/**
 * @param {number[][]} graph
 * @return {number}
 */
var shortestPathLength = function(graph) {
    const n = graph.length;
    if (n === 1) return 0;

    const target = (1 << n) - 1;
    const queue = [];
    // visited[node][mask]
    const visited = Array.from({ length: n }, () => new Array(1 << n).fill(false));

    // Multi-source BFS: start from every possible node
    for (let i = 0; i < n; i++) {
        const initialMask = 1 << i;
        queue.push([i, initialMask, 0]); // [currentNode, mask, distance]
        visited[i][initialMask] = true;
    }

    let head = 0;
    while (head < queue.length) {
        const [node, mask, dist] = queue[head++];

        if (mask === target) {
            return dist; // First time reaching full mask gives shortest path
        }

        for (const neighbor of graph[node]) {
            const nextMask = mask | (1 << neighbor);

            if (!visited[neighbor][nextMask]) {
                visited[neighbor][nextMask] = true;
                queue.push([neighbor, nextMask, dist + 1]);
            }
        }
    }

    return 0;
};
```
