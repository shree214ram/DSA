### 🚀 Google-Level Level Up: From $O(2N)$ to Strict $O(N)$

While your solution is perfectly optimal for an interview ($O(N)$ time complexity because each character is visited at most twice—once by `i` and once by `start`), you can optimize it to run even faster.

Instead of using a `Set` and shrinking the window step-by-step with a `while` loop, you can use a **`Map` to store the last seen index of each character**. This allows your `start` pointer to instantly **jump** right past the duplicate character in $O(1)$ time without any inner looping.

Here is how cleanly that compresses your logic:

```javascript
var lengthOfLongestSubstring = function (s) {
    const map = new Map(); // Stores: character -> index
    let maxL = 0;
    let start = 0;

    for (let i = 0; i < s.length; i++) {
        // If we've seen the character and it's inside our current window
        if (map.has(s[i]) && map.get(s[i]) >= start) {
            start = map.get(s[i]) + 1; // Instantly jump the start pointer
        }
        
        map.set(s[i], i); // Record/update the newest index of this character
        maxL = Math.max(maxL, i - start + 1);
    }
    return maxL;
};
```
